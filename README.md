# Restoral - Fast Food Restaurant & Pizza Bar

A complete, fully functional, multi-page website clone recreation of the **Restoral Fast Food Restaurant** website. Built with **React, Vite, HTML5, CSS3, and JavaScript**.

## 🚀 Quick Start in VS Code

1. Open this folder directly in **VS Code** (`File` > `Open Folder...`).
2. Open the built-in terminal (`Ctrl + ~` or `Terminal` > `New Terminal`).
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the local preview link:
   [http://localhost:5173/](http://localhost:5173/)

To build for production:
```bash
npm run build
```

## 🍽️ Pages Included & Functional

All 14 linked pages are fully implemented and accessible via top navigation, dropdowns, and buttons:

1. **Home (`index.html` / `/`)** - Hero swiper slider with 3 slides, counters, values, specialty dishes, promo banners, chefs, partners, gallery preview, and testimonials.
2. **Home Boxed Layout (`index-2.html`)** - Elegant boxed container presentation.
3. **About Us (`about.html`)** - Restaurant story, heritage, quality checklist, statistics, and culinary values.
4. **Menu Classic (`menu-classic.html`)** - Full multi-category menu with category filter pills, real-time dish search, prices, and "+ Add" order buttons.
5. **Menu Single / Categories (`menu-single.html`)** - Visual category tabs (Pizzas, Burgers, Drinks, Toasts, Salads, Desserts) with food cards, ingredients, and customization.
6. **Gallery (`gallery.html`)** - Photo gallery with category filter tabs and interactive fullscreen **Lightbox Modal**.
7. **Team (`team.html`)** - Roster of executive chefs, biographies, social links, and career recruitment section.
8. **Deals & Combos (`deals.html`)** - Value meal bundles with discount badges, savings percentages, and 1-click cart addition.
9. **Privacy Policy (`privacy.html`)** - Comprehensive privacy, cookie, data encryption, and security policy.
10. **Classic Blog (`classic-blog.html`)** - Magazine stream of articles, sidebar with live search, categories, recent posts, and tag cloud.
11. **Grid Blog (`grid-blog.html`)** - 2-column card grid layout for news and food recipes.
12. **Masonry Blog (`masonry-blog.html`)** - Responsive masonry layout of stories and chef quotes.
13. **Blog Post (`blog-post.html`)** - Single article detail page with full story, author bio, and **interactive live comment submission system**.
14. **Contacts (`contacts.html`)** - Interactive "Get In Touch" contact form with live validation, hours, phone, and location details.

## ✨ Interactive Features

- **Slide-out Cart & Checkout Drawer:** Quantity controls, item removal, discount coupon support (`PIZZA50` for 50% off, `SAVE20` for 20% off), delivery address form, and celebratory confetti upon checkout.
- **Table Reservation Modal:** Accessible via the header phone number or reserve buttons with date, time, and guest party picker.
- **Quick Dish Customization Modal:** Customize toppings (extra melted cheese), select quantity, and add directly to your order.
- **Fullscreen Lightbox:** Preview gallery photos with next/previous arrow navigation and keyboard escape.
- **Original High-Definition Assets:** All 90 original images and 25 icon font packages located in `public/`.
- **Responsive Layout:** Mobile hamburger navigation drawer, sticky top navbar on scroll, and back-to-top button.
